Version 1.0.0 - 20/09/2026 - Initial release
Version 1.1.0 - 22/09/2026 - Added support for GPS tag recording, shutter speed,
                             ISO sensitivity
                           - theta_grab_timelapse_images.py now reconfigures the
                             camera for day or night capture at dawn or dusk
                             automatically based on GPS data
                           - Various minor improvements
Version 1.2.0 - 23/09/2026 - Added support for WLAN antenna configuration,
                             shutter volume, and live preview format setting
                           - theta_grab_timelapse_images.py now uses location
                             data from configuration file rather than from the
                             camera's GPS, in case GPS reception is flaky
                           - theta_grab_timelapse_images.py now configures the
                             camera for static switching, to avoid deforming
                             star trails along the stitc line
                           - Various bugfixes
Version 1.3.0 - 04/10/2026 - Added support to turn bluetooth on/off, stop the
                             self-timer, setting the WLAN AP password to the
                             class and the theta_do.py utility
                           - Added inplicit "ap" camera in theta_do.py, to
                             address the camera in direct mode (maybe be
                             redefined in the credentials file). Direct-mode
                             commands use use the "ap" camera by default if no
                             other name is supplied
                           - list files in ISO 8601 format rather than Ricoh's
                             nonstandard format
                           - Less aggressive polling to wait for a photo to be
                             taken, to prevent overloading the camera's embedded
                             web server
                           - Recoded theta_grab_timelapse_images.py to handle
                             taking photos, querying the state of the camera and
                             reconfiguring it for daytime or nighttime capture
                             as separate events with their own schedule.
                           - theta_grab_timelapse_images.py now turns off the
                             camera when the battery drops below 30% to prevent
                             damage to the cell
                           - theta_grab_timelapse_images.py saves the current
                             events' timestamps so that, if it's stopped and
                             immediately restarted for some reason, it resumes
                             the previous events' schedule. This is mostly
                             useful to keep taking photos at the same intervals
                             even if the script has to be restarted
                           - In theta_grab_timelapse_images.py, added
                             -i / --intervalometer option to skip taking photos,
                             but otherwise keep querying the state of the camera
                             and reconfigure it for daytime / nighttime capture.
                             This is useful when the shots are triggered by an
                             external intervalometer - typically bluetooth -
                             to prevent disrupting the timing of the photos if
                             the wifi link is not very good - in other words,
                             the photos are always taken on time, but the camera
                             monitoring and daytime / nighttime reconfiguration
                             may fail temporarily, which is less of a problem
                           - Don't take timelapse photos in silent mode, but
                             instead lock the UI and mute the shutter, as silent
                             mode seems to make the wifi connection - and
                             possibly the entire camera - unstable over time.
                           - Bugfixes
Version 1.3.1 - 05/10/2026 - Fix bug that crashed theta_grab_timelapse_images.py
                             when switching daytime / nighttime if the script
                             was restarted and reused saved event timestamps
Version 1.4.0 - 12/10/2026 - Added support for getting and setting the camera's
                             date / time / timezone
                           - Renamed "capturemode" to "mode" in theta_do.py
                           - Optimized nighttime capture parameters for a faster
                             shooting pace in theta_grab_timelapse_images.py
Version 1.4.1 - 17/10/2026 - Added support for getting / setting the POV
                             compensation and yaw / pitch / roll angles
                           - Downgraded the daytime capture resolution to
                             5504x2752 in theta_grab_timelapse_images.py to
                             improve the cameras's stability when when shooting
                             very long timelapses
                           - In theta_grab_timelapse_images.py, disabled POV
                             compensation entirely to prevent micro-movements
                             in timelapses due to noise in the camera's sensors
Version 1.4.2 - 21/10/2026 - Corrected the timing of camera state check events
                             in theta_grab_timelapse_images.py
                           - Added -d / --download switch to the view command in
                             theta_do.py to download a Theta URL permanently
Version 1.4.3 - 23/10/2026 - Correctly set the date / time / zone
Version 1.5.0 - 24/10/2026 - Added compile_theta_images.py program and sample
                             shell script to process Theta photos shot at
                             regular intervals and render them into timelapse
                             videos or combined images
Version 1.6.0 - 25/10/2026 - Added GIMP plugin to tag stuck pixels with
                             selection boxes and log the coordinates of the
                             selections in the XWindow geometry format
                             understoo by compile_theta_images.py to apply
                             delogo filters on the stuck pixels
                           - Improvements / bugfixes to compile_theta_images.py
